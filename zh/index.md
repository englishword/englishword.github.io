# 音形意
# 统一记忆法

音形意统一记忆法（IPSM Approach）是一种英语单词记忆法，通过对单词进行音素标注与词素划分，突显发音规则与构词规则，高效记忆单词。包括：IPS 音形统一、ISM 形意统一、IPM 音意统一。
