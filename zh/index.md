# 音形意
# 统一记忆法

音形意统一记忆法（IPSM Approach）是一种英语单词记忆法，通过对单词进行音素标注与词素划分，突显发音规则与构词规则，高效记忆单词。它把通常分开教学的三个角度统一在一起：

- **IPS 音形统一**：用音素标注符号把发音规则直接融入单词，让拼写本身就能体现读音。
- **ISM 形意统一**：用词素划分把构词规则融入单词，让承载词意的构造在拼写中可见。
- **IPM 音意统一**：体会单词的音素音律与词意之间的内在联系。
