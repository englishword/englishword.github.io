## 核心音节

每个单词都有一个核心音节，核心音节为整个单词最重要的音节，无论是听、说、读还是写，都应准确把握它。通常情况下，核心音节由核心字母与其后的重读元音组成。

在听的时候，应将注意力集中在核心音节上，核心音节前后通常都为弱读，所以只要准确把握了核心音节，就易于听明白整个单词的意义。

在说的时候，应将核心音节准确发音，只有这样才能使你的听众准确听清你所想表达的单词。

在阅读的时候，应将注意力首先集中在核心字母、核心音节上，一眼抓住核心字母，正所谓"打蛇打七寸"，这样对提高阅读速度非常有帮助。

在写的时候，尽量不要写错核心音节所包含的几个字母，只要核心音节字母没写错，即使其它字母写错，也不至于使整个单词错得太离谱。

如intimidate（in-𝓽im-id-āte）其核心音节为𝓽im，一眼抓住"𝓽"字母，眼睛余光扫略其他字母，瞬间就能明白整个单词内在意思，而不再是从"i"字母遍历到"e"字母，i→n→t→i→m→i→d→a→t→e，然后再从大脑中检索出它的汉语意思。这种能力应该通过多加练习，培养出来。

## 核心音素

每一个单词都有一个或两个核心字母。核心字母通常都是单词首字母或词根首字母。没有前缀的单词为单词首字母，有前缀的单词为词根首字母。由于英语有多辅音组合，所以多辅音也是核心字母，核心字母情况如表22所示：

| 组合情况 | 核心字母 |
| --- | --- |
| 元音 | a, e, i, o, u |
| 单辅音 | b, c, d, f, g, h, j, k, l, m, n, p, qu, r, s, t, v, w, x, y, z |
| 双辅音 — 辅音+l | bl-, cl-, fl-,gl-, pl-,sl- |
| 双辅音 — 辅音+r | br-, cr-, fr-, gr-, pr-, tr-, dr- |
| 双辅音 — s+辅音 | sc-, sk-, sm-, sn-,sp-, st-, sw- |
| 双辅音 — 其他 | tw- |
| 三辅音 | scr-, spr-, str-, shr-, thr-, spl- |

核心字母通常由辅音字母充当，少数情况下为元音字母。

一部分单词是组合词，这些单词为两个单词组合，所以也就有两个核心字母。如goodbye的核心字母为G和B。

在记忆单词时，我们应该尽量将单词的词意与单词的核心字母、音素和词素建立起一种联系，这样一方面能使我们更准确在体会到26个字母的内涵，另一方面对我们获悉单词的模糊意会很有帮助，这种能力应在记忆单词的过程中慢慢培养。

如good, great, God等的核心字母为G，于是我们就知道，G字母带有一种美好的感觉；又如，home, house, hold, have, help,于是我们就知道，H字母有持有，保护的意思；再如，light, relate, lace, line, long, 于是我们就知道，L字母有线，联系的意思。

除去核心字母以外的辅音字母，也能承载一部分语意，但这不是重点，本书不探讨这部分辅音字母，如full,fill中的ll字母，good中的d字母。有兴趣的读者可以自行深入思考。

在本书第三章对所有单词的核心字母都用黑体加粗标示，26个字母的内涵更多的还是要靠读者自己在学习过程中慢慢体会。

## 核心音素意义

万物皆有声响，人类语言就是从模仿外界声音开始的，因此，体会音素的意义要静下心来感悟大自然，将"音"放在"心"上，便能感受到"意"。对音素的意义简述如下，帮助理解。

### 元音音素的意义

元音的发音也同样具有丰富的意义，元音的意义可以从声音的"长"、"短"、"强"、"弱"等方面去体会。总的来说为：

- 开音响亮，重要；
- 闭音紧张，强调；
- 长音和缓，轻柔；
- 短音催促，急躁；
- 重音清晰，明确；
- 弱音模糊、随意。

## 辅音静，元音动

通过多门语言的对比发现，不同语言语音的主要区别在于元音上，而辅音的发音基本相同，这主要是由人的发音器官决定的，这个特征可以形像比喻为**"辅音静若磐石，元音动若流水"**。

由于元音字母的发音变化多端，辅音字母的发音较为固定，所以元音适合于承载语音，辅音适合于承载语意。

英语单词的时态或词性变形，变化的多是元音，辅音通常不发生变化，这主要就是由于词意基本不变，所以辅音字母不发生变化。如：

1）动词原形，过去式，过去分词的变形

begin    began    begun

bite     bit      bitten

see      saw      seen

2)词性变化

full      fill

sit       seat

choose    choice

bind      band

因为人类自身条件是相同的，人类生存的环境也是相同的，这从最根本上决定了，不同语言在语音上必将殊途同归。以下举几个最浅显的例子。从这几个例子中可以看出不同语言的音和意是相通的。这种情况在动词中表现得尤为明显，举例如下。
