**발음·철자 표기(IPS 표기)** — 이것은 직접적인 행내 음성 표기의 한 종류로, 단어의 철자를 바꾸지 않고 모음자와 일부 자음자 위에 기호를 배치하여 단어의 다른 읽기를 구분합니다. IPA 기호나 다른 재표기 시스템보다 간결합니다.

IPSM 방법은 단어의 주요 모음 발음을 — "강한" 것부터 "약한" 것으로 — 4가지 리듬으로 나눕니다: 개음절, 폐음절, 경음절, 약음절입니다. 개음절은 가로선(─)으로 표시되고, 폐음절은 기호가 없으며(∅), 경음절은 점(⦁)으로 표시되고, 약음절은 원(○)으로 표시됩니다.

IPS 표기와 IPA는 1대1로 대응하며, 단어의 IPA를 IPS로 변환할 수 있고, 그 반대도 가능합니다. 독자가 아직 IPA를 습득하지 못했더라도 IPS 학습에는 지장이 없습니다. 이미 IPA를 습득했다면 IPS 학습에 도움이 될 뿐만 아니라 IPA에 대한 이해도 깊어집니다.

IPA에 비해, IPS는 단어의 발음 규칙에 따라 만들어져 간결하고 명확합니다. 그 섬세한 영향으로 인해, 사람은 단어의 발음 규칙을 익히고 음성 표기는 더 이상 필요 없게 됩니다.

IPS 표기는 26개의 영문자와 중국어 병음을 알고 있는 초등학교 2학년 학생도 습득할 수 있습니다.

## 일반적인 접미사의 발음

-ed와 -s/-es의 발음 규칙은 고정되어 있습니다. 본서에서는 개별적으로 표기되지만, 간결함을 위해 표기 없이도 무방합니다.

-ly, -ous, -ity 등의 다른 접미사는 규칙적으로 발음됩니다. 본서에서는 모두 표기되지만, 발음이 일정하므로 간결함을 위해 표기 없이도 무방합니다.

### 접미사 -ed

| -ed의 발음 규칙 | 예 |
|---|---|
| 유성 자음 및 모음 뒤 [𝕖d] ⟹ [d] | call𝕖d, borrow𝕖d, mov𝕖d |
| 무성 자음 뒤 [𝕖ḋ] ⟹ [t] | ask𝕖ḋ, finish𝕖ḋ, help𝕖ḋ |
| [t] 음 뒤 [ėd] ⟹ [id] | wantėd, startėd |
| [d] 음 뒤 [ėd] ⟹ [id] | needėd, countėd |

### 접미사 -s/-es

| | -s(-es)의 발음 규칙 | 예 |
|---|---|---|
| 자음 뒤 | [s], [z], [sh], [s̃], [ch], [j] 음 뒤에는 -es를 붙이고, [ėṡ] ⟹ [iz]로 발음함 | glassėṡ, buzzėṡ, washėṡ, teachėṡ |
| | 무성 자음 뒤에는 s를 붙이고, [s] ⟹ [s]로 발음함 | books, typ𝕖s |
| | 유성 자음 뒤에는 s를 붙이고, [ṡ] ⟹ [z]로 발음함 | bagṡ, lin𝕖ṡ, besid𝕖ṡ |
| 모음 뒤 | 문자 o 뒤에는 -es를 붙이고, [𝕖ṡ] ⟹ [z]로 발음함 | tomato𝕖ṡ, potato𝕖ṡ, do𝕖ṡ |
| | -y는 i로 바뀌어 -es를 붙이고, [𝕖ṡ] ⟹ [z]로 발음함 | ladi𝕖ṡ, fli𝕖ṡ |
| | 그 외의 경우 [ṡ] ⟹ [z]로 발음함 | newṡ, dayṡ, boyṡ, beeṡ |

## 묵음
