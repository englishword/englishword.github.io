**音形標記(IPS表記)** — これは直接的な行内音声表記の一種であり、単語のつづりを変えずに、母音字と一部の子音字の上に記号を配置することで、単語の異なる読み方を区別します。IPAの記号やその他の書き換えシステムよりも簡潔です。

IPSMメソッドは、単語の主要な母音の発音を — 「強い」ものから「弱い」ものへ — 4つのリズムに分けます:開音節、閉音節、軽音節、弱音節です。開音節は横線(─)で示され、閉音節には記号がなく(∅)、軽音節は点(⦁)で示され、弱音節は円(○)で示されます。

IPS表記とIPAは1対1で対応しており、単語のIPAをIPSに変換でき、その逆もできます。読者がまだIPAを習得していなくても、IPSの学習に支障はありません。すでにIPAを習得していれば、それはIPSの学習に役立つだけでなく、IPAの理解を深めることにもつながります。

IPAに比べ、IPSは単語の発音規則に従って作られており、簡潔で明快です。その繊細な影響により、人は単語の発音規則を身につけ、音声標記はもはや不要になります。

IPS表記は、26個の英字と中国語のピンインを知っている小学2年生でも習得できます。

## 母音字 + R

### 開音 + R

| 開音 + R | [ ār ] = [ er ] | [ ēr ] = [ ir ] | [ īr ] | [ ōr ] = [ or ] | [ ūr ] |

## 一般的な接尾辞の発音

-ed と -s/-es の発音規則は固定されています。本書では個別に標記されますが、簡単のため標記なしでもかまいません。

-ly, -ous, -ity などの他の接尾辞は規則的に発音されます。本書ではすべて標記されますが、発音が一定なので、簡単のため標記なしでもかまいません。

### 接尾辞 -ed

| -ed の発音規則 | 例 |
|---|---|
| 有声子音および母音の後 [𝕖d] ⟹ [d] | call𝕖d, borrow𝕖d, mov𝕖d |
| 無声子音の後 [𝕖ḋ] ⟹ [t] | ask𝕖ḋ, finish𝕖ḋ, help𝕖ḋ |
| [t] 音の後 [ėd] ⟹ [id] | wantėd, startėd |
| [d] 音の後 [ėd] ⟹ [id] | needėd, countėd |

### 接尾辞 -s/-es

| | -s(-es) の発音規則 | 例 |
|---|---|---|
| 子音の後 | [s], [z], [sh], [s̃], [ch], [j] 音の後には -es を付け、[ėṡ] ⟹ [iz] と発音する | glassėṡ, buzzėṡ, washėṡ, teachėṡ |
| | 無声子音の後には s を付け、[s] ⟹ [s] と発音する | books, typ𝕖s |
| | 有声子音の後には s を付け、[ṡ] ⟹ [z] と発音する | bagṡ, lin𝕖ṡ, besid𝕖ṡ |

| | その他の場合は [ṡ] ⟹ [z] と発音する | newṡ, dayṡ, boyṡ, beeṡ |
